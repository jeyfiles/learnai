# Tool facts used in the lessons

The site is for adults and older learners building AI careers, so lessons show one short `access` line instead of age rules. The age limits below are kept here as facts, because some tools (Claude) block younger users.

Checked on **26 September 2026**. Tools change their screens and plans often. When a lesson is re-checked, update its `lastReviewed` date and this file.

## Things I could not confirm (shown on the lessons in a "Good to know" note)

- **Microsoft Copilot:** the exact name of the file upload button. Microsoft's help page did not load for me, so the lesson says "the **+** or paperclip button" and asks learners to hover to find it.
- **Perplexity:** whether the "Focus" menu for choosing source types (for example Academic) is still shown on the free plan. The lesson does not depend on it.
- **Gemini Notebook:** NotebookLM was renamed on 16 July 2026. Some screens and help pages may still say NotebookLM. The lessons use both names.
- **Gemini Guided Learning:** Google's help page says the menu is reached from the add files button and then **More tools**. On phones this may look different.
- **ChatGPT:** the upload menu wording. The lessons say "click **+** and choose the option to add photos and files".
