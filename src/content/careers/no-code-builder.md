## How to start

1. Finish Level 1, especially "Test two AI tools on the same task", and keep a prompt test log.
2. Level 4 covers assistants and automations in depth. Until it opens, practise building one custom assistant in ChatGPT or Gemini.
3. Write up everything you build, including what went wrong and how you fixed it.

## What to watch for

Many roles on this path sit in operations or IT teams. Some later ask for basic scripting, so learning a little code over time widens your options.
