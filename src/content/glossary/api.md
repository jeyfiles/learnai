term: API
category: Building with AI
definition: Short for application programming interface. A structured way for one piece of software to send requests to another and get results back.
whyItMatters: AI engineers call models through APIs to build apps. No-code tools often use the same APIs behind the scenes.
example: An app sends a customer's question to a model's API and shows the model's reply on screen.
