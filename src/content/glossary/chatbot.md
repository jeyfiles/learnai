---
term: Chat tool (chatbot)
category: Basics
definition: An app where you type or speak a message and an AI replies in a conversation.
whyItMatters: The conversation so far affects the next answer, so starting a new chat for a new task avoids mix-ups.
example: Starting a New chat for your portfolio write-up keeps questions from an earlier coding chat from affecting the answers.
