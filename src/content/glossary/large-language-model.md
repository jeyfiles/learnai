---
term: Large language model (LLM)
category: Basics
definition: The engine behind chat tools. It has learned patterns from huge amounts of text and writes by predicting which words should come next.
whyItMatters: Because it predicts likely words, it can write something that sounds right but is false.
example: ChatGPT, Gemini and Claude are chat tools built on large language models.
related:
- hallucination
- token
