---
term: Retrieval-augmented generation (RAG)
category: Building with AI
definition: A way of building AI apps where the system first finds relevant passages from a set of documents, then gives them to the model so it can answer from them.
whyItMatters: It is one of the most common patterns in real AI products, because it lets a model answer from a company's own, up-to-date documents.
example: A help-desk assistant that searches the product manual before it answers a customer's question.
related:
- embeddings
- vector-database
- grounding
