title: The AI gave me a wrong answer
order: 12
category: When answers go wrong
question: I checked, and the answer was wrong. What now?
shortAnswer: This happens. Tell the tool what is wrong, point it to the right source, and check the new answer too. For anything important, trust the official source over the tool.
steps:
- Say exactly which part is wrong and why, for example "Point 3 does not match page 4 of the official docs."
- Paste or upload the correct source and ask it to use only that.
- Check the corrected answer, since fixes can add new mistakes.
- If it keeps getting it wrong, stop and go to the official documentation or ask someone who knows the topic.
- Note the mistake. It tells you what this tool is weak at.
success: You have a correct answer that you checked against a trusted source.
prompt: 'Your answer about [topic] is wrong in this part: [quote it]. The correct information from the official source is: [paste it]. Correct your answer using only this source, and mark what you changed.'
