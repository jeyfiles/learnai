---
title: Do I need to code to work in AI?
order: 1
category: Careers in AI
question: I have never written code. Can I still build a career in AI?
shortAnswer: It depends on the path. Many AI-related roles need little or no code, such as using AI in your own field, building with no-code tools, or AI product work. Engineering and machine learning roles need real coding skill. You can start on a no-code path and learn code later.
steps:
- Read the career paths page and note how much coding each path needs.
- Look at five real job posts for the role you want and count how many ask for coding.
- If coding is required, start with one language most AI teams use, such as Python, alongside Level 1.
- If it is not required, focus on showing strong AI use and judgement in your portfolio.
success: You know how much coding your target role really needs, based on real job posts.
