title: It gave me a source that does not exist
order: 13
category: When answers go wrong
question: I searched for the book or article it mentioned and could not find it.
shortAnswer: Chat tools sometimes invent sources that look real. Never cite a source you have not opened yourself.
steps:
- Search for the exact title in quotes, and check the author's name.
- If you cannot find it, treat it as made up and do not use it.
- Ask the tool to give only sources with working links, then open each one.
- For research, use a tool that shows citations, or search a library database.
- Remove any claim that relied on the missing source, unless you find it elsewhere.
success: Every source in your work is one you have opened and read.
prompt: Only list sources you are confident exist, with a working link for each. If you are not sure a source exists, say so instead of listing it.
